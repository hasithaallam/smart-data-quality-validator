# Smart Data Quality Validator

## Project Overview
A Java Spring Boot application that validates vehicle registration numbers using predefined rules and stores validation records in PostgreSQL.

## Technologies Used
- Java
- Spring Boot
- PostgreSQL
- REST APIs
- HTML, CSS, JavaScript

## Features
- Vehicle registration number validation
- REST API-based validation
- Validation history storage
- Handling of valid and invalid inputs

## API Endpoints
- `/api/vehicle/health` - Application health check
- `/api/vehicle/validate` - Vehicle number validation

## Testing
Test the application using valid, invalid, and unexpected inputs to verify validation rules and API responses.
